# LA FORÊT - Agence Immobilière

LA FORÊT is a premium real estate agency website for the Algerian market, combining a public-facing property showcase with a private admin dashboard.

## Project Structure

This is a monorepo containing:
- `frontend/`: Next.js 16 (App Router) public marketing site & admin panel.
- `backend/`: Node.js + Express.js REST API.

## Requirements
- Node.js 18+
- MongoDB instance (Atlas)
- Cloudinary account

See individual `frontend/README.md` and `backend/README.md` for specific instructions.
